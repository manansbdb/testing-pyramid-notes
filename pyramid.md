# The Pyramid / A Pirâmide

## English

```text
        /\\n       / E2E \\         few, slow, high confidence on critical paths
      /--------\\
     / Integration \\   contract + DB/API boundaries
    /--------------\\
   /     Unit        \\ many, fast, isolate pure logic
  /------------------\\
```

## Português

```text
        /\\n       / E2E \\         poucos, lentos, alta confiança em caminhos críticos
      /--------\\
     / Integração \\   contratos + fronteiras DB/API
    /--------------\\
   /     Unitário    \\ muitos, rápidos, isolam lógica pura
  /------------------\\
```
