# Practical Tips / Dicas Práticas

## English
- Fail flaky E2E in quarantine; fix root causes.
- Test behavior, not implementation details.
- Prefer deterministic fixtures over live network in unit tests.
- Keep CI feedback under a few minutes for the default PR suite.

## Português
- Isole E2E flaky em quarentena; corrija causas raiz.
- Teste comportamento, não detalhes de implementação.
- Prefira fixtures determinísticas a rede live em unitários.
- Mantenha o feedback do CI em poucos minutos para a suite default de PR.
