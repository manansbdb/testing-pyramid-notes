# Testing Pyramid Notes / Notas da Pirâmide de Testes

Testing strategy guide using the classic pyramid model.

Guia de estratégia de testes com o modelo clássico da pirâmide.

## English

Favor many fast unit tests, fewer integration tests, and a thin layer of E2E.

## Português

Prefira muitos testes unitários rápidos, menos integração e uma camada fina de E2E.
